# AR Building — Exhibition Viewer

Этот каталог предназначен для размещения внутри существующего GitHub-репозитория `ar-building`.

Структура:

ar-building/
├── index.html                 # существующий AR-проект — НЕ ТРОГАТЬ
└── exhibition/
    ├── index.html             # выставочный viewer
    └── plans/
        ├── 1.svg
        └── 6.svg

После публикации через GitHub Pages viewer будет доступен по адресу:

https://YOUR-USERNAME.github.io/ar-building/exhibition/

`exhibition/index.html` является самостоятельным HTML-файлом и не требует внешнего сервера или библиотек.
